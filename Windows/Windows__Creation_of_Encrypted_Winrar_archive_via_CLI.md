# Creation of Encrypted Winrar archive via CLI

## Description
Alert generated by the `Creation of Encrypted Winrar archive via CLI` detection. This prompt is designed to detect the creation of an encrypted RAR archive using the command-line interface of WinRAR (`rar.exe`). Attackers often use this technique for defense evasion by exfiltrating data in an encrypted format to bypass data loss prevention (DLP) systems and make it difficult for security analysts to inspect the contents. The prompt focuses on the use of the `'-hp'` flag, which indicates the use of a password to encrypt the archive. The alert must be reviewed by the SOC to validate its legitimacy, scope, affected asset, and potential impact.

## Objective
Detect and prioritize potential malicious, anomalous, or unauthorized activity related to Windows host, enabling the SOC to initiate a structured investigation, reduce operational risk, and activate containment procedures when indicators of compromise are identified.
